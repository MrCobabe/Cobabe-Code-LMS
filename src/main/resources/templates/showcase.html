Java 25 Required to Run Projects

Our downloadable projects are Java desktop applications. To run them on your computer, we recommend installing Java 25 first. Java is free, and you only need to install it once to run compatible projects.

Download for Windows ↗ Download for macOS ↗ Download for Linux ↗

Choose a Java 25 installer for your operating system and processor. After installation, download a project and run its executable JAR file. If double-clicking doesn't work, open a terminal in the download folder and enter: java -jar filename.jar
